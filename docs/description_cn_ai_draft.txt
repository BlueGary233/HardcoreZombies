[h1]腐风 · 硬核丧尸[/h1]

丧尸闻得到尸体的气味，会循味而来、排队进食。吃饱的丧尸更强，饿久了的丧尸会变弱，营养满的丧尸会开始奔跑。

[h2]这个 mod 做了什么[/h2]
[list]
[*][b]尸体气味[/b]：新鲜尸体气味弱，腐烂后扩散得最远，之后逐渐衰减。气味随风向偏移，上风口的丧尸先闻到。
[*][b]排队进食[/b]：每个尸堆有固定餐位，多出来的丧尸在旁边等着，不会一拥而上互相卡住。
[*][b]营养成长[/b]：进食累积营养，营养推着丧尸的五维往上走；营养满的丧尸开始奔跑。
[*][b]尸体骨化[/b]：被吃空的尸体变成骨架，身上的装备全部落地并损坏。
[*][b]室内尸堆[/b]：房间里的尸堆只扫房间格子，不会隔着墙把外面的丧尸叫进来。
[*][b]认领机制[/b]：一只丧尸只跟一个尸堆，不会在两个堆之间来回跑。
[/list]

[h2]营养系统：吃出来的成长，也会饿回去[/h2]

每只丧尸有两条进度：[b]饱食度[/b]（0–5）和[b]营养值[/b]（0–5）。

[list]
[*][b]吃[/b]：吃空一具尸体，饱食度补满（+5）。饱食度满的时候闻不到气味、也不会再接单，消化一点之后才重新开始找吃的。
[*][b]消化[/b]：每 [i]消化间隔[/i] 个游戏小时，饱食度 -1，同时按 [i]转化比例[/i] 折成营养值。
[*][b]饿[/b]：营养值每天自然下降；饱食度为 0 的时候，下降速度翻倍。
[/list]

营养值决定[b]五维[/b]，每跨过一个阶段（整套 17 级），就从还没满的维度里随机挑一项 ±1：

[list]
[*][b]生命[/b] 0.5 → 4.0（7 级）
[*][b]速度[/b] 3 → 1（3 级，1 = 跑尸）
[*][b]力量[/b] 1 → 5（5 级，影响砸门/砸窗的伤害）
[*][b]视觉[/b] 3 → 1（3 级）
[*][b]听觉[/b] 3 → 1（3 级）
[/list]

于是同一只丧尸会经历这样的曲线：刚吃饱 → 一路变强 → 营养满开始跑 → 长时间没吃的 → 五维逐级掉回最低，连走路都变慢。营养低于 0.5 时五维锁在最低，高于 4.75 时锁在最高。

[h2]世界曲线：丧尸会随天数整体变强或变弱[/h2]

沙盒里的「硬核丧尸」页控制的是[b]整局的时间尺度[/b]，不是单只丧尸：

[list]
[*][b]饱食度曲线[/b]：初始值 → 峰值 → 最低值，配合「峰值日」「归零日」。意思是从第 0 天开始，新进表的丧尸起点饱食度会先升后降。
[*][b]营养曲线[/b]：同样的三段（以百分比表示），控制新丧尸的五维起点：前期 100%，中期可以拉到 200%，后期掉到 10%。
[*][b]曲线指数[/b]：1 = 线性，2 = 二次（峰值段保持更久），越大两端越陡。
[/list]

默认值的效果：前 90 天丧尸整体变强（第 90 天营养 200%），之后开始衰退，第 360 天掉到 10%。想让丧尸越打越弱就把峰值日调小，想让末世后期依然凶就把最低值调高。

[h2]气味也能调[/h2]

[list]
[*][b]腐烂延迟[/b]：尸体多少游戏小时后开始发臭（可设上下限随机）。
[*][b]腐龄满值[/b]：腐烂多少小时后气味达到最强。
[*][b]数量加成[/b]：多少具尸体叠在一起时，数量这一项达到满值。
[*][b]半径[/b]：气味能传多远（格），最小/最大之间按腐龄和数量插值。
[*][b]浓度[/b]：吸引强度，浓度越高丧尸越专注，越容易忽略玩家的脚步、气味甚至枪声。
[*][b]权重[/b]：半径与浓度各自受「腐龄」和「数量」影响的比例，两个权重自动互补。
[/list]

[h2]其他可调项[/h2]

[list]
[*][b]尸堆大小[/b]：多少格范围内的尸体合并成一个尸堆。
[*][b]每具尸体进食上限[/b]：同格最多几只丧尸一起吃，调太高会互相卡住。
[*][b]吃完一具的时间[/b]：一只丧尸吃空一具尸体需要多少游戏分钟。
[*][b]骨化时间[/b]：没人吃的尸体多久后自然变成骨架。
[*][b]进食判定距离[/b]：离尸体多近才算到达餐桌。
[*][b]动作间隔[/b]：每多少现实秒处理一个尸堆，越小反应越快、开销越高。
[*][b]丧尸表刷新倍率[/b]：位置表多久刷新一次，越新派单越准、越旧越省性能。
[/list]

[h2]性能[/h2]
200 具尸体 + 20 只丧尸，调试日志全开的情况下约 0.7ms/帧（最大的一项 tickPiles 0.45ms）。
所有周期任务各自排队，每拍只推进一个；Lua 侧不保存丧尸状态的副本，直接读 modData。
