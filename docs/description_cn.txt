[h1]硬核丧尸[/h1]

丧尸闻得到尸体的气味，会循味而来、排队进食。吃饱的丧尸更强，有更厚的血量和更灵敏的听力视力等，营养满的会变为跑尸。

[h2]这个 mod 做了什么[/h2]

[list]
[*][b]尸体气味[/b]：新鲜尸体气味弱，腐烂后扩散得最远，之后逐渐衰减。气味会随风向偏移，上风口的丧尸先闻到。
[*][b]排队进食[/b]：每个尸堆有固定餐位，多出来的丧尸在旁边等着，不会一拥而上互相卡住。
[*][b]营养成长[/b]：进食累积营养，营养随时间消化，营养满的丧尸会变为超级跑尸。长时间饥饿的丧尸数值会降低。
[*][b]尸体骨化[/b]：被吃空的尸体变成骨架，身上的装备全部落地并损坏。
[*][b]室内尸堆[/b]：房间里的尸堆只扫房间格子，不会隔着墙把外面的丧尸叫进来。
[/list]

[h2]背景设定[/h2]

丧尸间会同类相食，只会吃死丧尸的尸体。所以要是看到一具尸体没丧尸吃？小心复活！随着进食，腐肉带来的营养和病毒的累积会让丧尸变得更强！它会更耐打，速度更快，感知更灵敏，力量更大。mod在之后的更新还会增加原版类型外的丧尸作为丧尸的进化路线。

[h2]营养系统[/h2]

每只丧尸有两条进度：饱食度（0-5）和营养值（0-5）。

[list]
[*][b]吃[/b]：吃空一具尸体，饱食度补满。饱食度满的时候闻不到气味、也不再接单，消化一点之后才重新找吃的。
[*][b]消化[/b]：每过设定的消化小时数，饱食度 -1，按比例转成营养值。
[*][b]饿[/b]：营养值每天自然下降，饱食度为 0 时下降速度翻倍。
[/list]

营养值决定五维，每跨过一个阶段（共 17 级），就从还没满的维度里随机挑一项 +1 或 -1：
[list]
[*]生命 0.5 → 4.0（原版最高3.8，最低0.5，默认1.0）
[*]速度 3 → 1（1 = 跑尸）
[*]力量 1 → 5（影响砸门砸窗的速度，也会增加被丧尸围住时开饭的概率和被攻击受伤的概率）
[*]视觉 3 → 1
[*]听觉 3 → 1
[/list]

所以一只丧尸会经历：刚吃饱 → 一路变强 → 营养满变跑尸 → 长时间没吃 → 五维逐级掉回去，走得越来越慢。营养低于 0.5 时五维锁在最低，高于 4.75 时锁在最高。

[h2]世界曲线[/h2]
沙盒「硬核丧尸」页控制的是整局的时间尺度，不是单只丧尸：
[list]
[*][b]饱食度曲线[/b]：初始 → 峰值 → 最低，配合峰值日、归零日。丧尸的初始饱食度随游戏进行先升后降。
[*][b]营养曲线[/b]：同样的三段（百分比），控制丧尸的五维起点，游戏前期丧尸弱，中期强，后期弱。
[*][b]曲线指数[/b]：1 = 线性，2 = 二次，越大两端越陡。
[/list]

默认值下，前 90 天丧尸逐渐变强（第 90 天营养 200%），之后开始衰退，第 360 天掉到 10%。想越打越弱就把峰值日调小；想后期依然凶就把最低值调高。

[h2]性能[/h2]

在极端情况下（500+具尸体，200+个丧尸），本mod的平均lua时间占用小于20ms每秒，性能尖峰小于60ms每秒。日常游戏平均lua时间小于10ms每秒，性能损耗小于大部分hudmod。
如果遇到性能问题，请确保没有开启模组的调试模式，会造成卡顿。

[h2]已知问题[/h2]

[list]
[*]1.暂不支持联机，仅本地游戏生效。
[*]2.跑尸的营养值回落不会使其回到普通丧尸状态。
[*]3.爬尸无法进食。
[*]4.暂时没有做持久化保存，读档不能恢复之前丧尸的状态，会重新积攒营养值。
[*]5.调试模式（DebugMode）会持续写日志和快照，正常游玩请关闭。
[*]6.旧存档里的丧尸可能带着上一局的尸堆认领，进游戏后会自动作废重来。
[/list]

2、3、4将会在下个版本进行修复。1由于没有测试条件暂不考虑做联机适配。有能力的可以到 [url=https://github.com/BlueGary233/HardcoreZombies]GitHub 源码[/url] 获取源码自己修改。

[h2]气味相关数值[/h2]
[list]
[*][b]腐烂延迟[/b]：多少游戏小时后开始发臭，可设上下限随机。
[*][b]腐龄满值[/b]：腐烂多久气味达到最强。
[*][b]数量加成[/b]：多少具尸体叠在一起时，数量这一项拉满。
[*][b]半径[/b]：气味传播距离（格），在最小/最大之间按腐龄与数量插值。
[*][b]浓度[/b]：浓度越高丧尸越专注，越容易忽略玩家的脚步、体味甚至枪声。
[*][b]权重[/b]：半径与浓度各自受腐龄、数量影响的比例，两个权重互补。
[/list]

[h2]沙盒选项[/h2]
[list]
[*][b]硬核丧尸[/b]页：饱食度与营养曲线（初始值、峰值、归零日、曲线指数）
[*][b]Mod 选项[/b]：气味半径与音量、风偏权重、餐位数、进食时长、骨化时间、调试模式
[/list]
